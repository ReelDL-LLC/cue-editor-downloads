## Download

[Download the latest Cue Editor release](https://github.com/ReelDL-LLC/cue-editor-downloads/releases/latest)

- **Apple silicon:** choose the installer ending in `arm64.dmg` for a Mac with an Apple M-series chip.
- **Intel:** choose the installer ending in `x64.dmg` for a Mac with an Intel processor.

You can check your processor in **Apple menu > About This Mac**.

## Install

1. Download the installer for your Mac.
2. Quit Cue Editor if it is already running.
3. Open the installer and drag **Cue Editor** into **Applications**.
4. If prompted, replace the previous copy, then open Cue Editor from Applications.

Your existing projects remain in place. Older versions may show a trial or
license prompt; use the license supplied by the person who provided the app.
The guide explains behavior by version.

## Future updates

Starting with version 1.2.1, Cue Editor checks for updates automatically and offers
**Download Update** or **Remind Me Later**. Nothing downloads until you accept.
After downloading, you can restart to install or keep working until you quit.

You can also choose **Cue Editor > Check for Updates…**.

This repository contains user documentation, practice files, and releases. The additional
archives and verification files attached to releases are used by the updater;
choose the `.dmg` installer when installing manually.
