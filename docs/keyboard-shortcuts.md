# Cue Editor Keyboard Shortcuts

Default shortcuts for Cue Editor 2.6.5 on Mac. Open **Settings → Keyboard Shortcuts…** to inspect or change your installed bindings.

**Command** is ⌘, **Option** is ⌥, **Control** is ⌃, and **Shift** is ⇧. A plus sign joins keys pressed together. Numeric-keypad keys are separate from the number row.

Visibility labels are ON (Onscreen), OS (Offscreen), and VO (Voiceover); combined labels show the order of a visibility transition. QC (Quality Control) review checks each cue.

The scope matters: text fields retain ordinary typing, selection, and cursor keys. Cue clipboard actions operate on cues when the timeline is focused and on text when a field is focused. **Shift+Space** starts playback from a cue field.

## Review actions

Use **Command+Enter** for the primary review action shown by the current mode, such as **Approve**, **Resolved**, or accepting the default On/Off value. **Tab** accepts a field suggestion and **Escape** dismisses it where offered. These contextual actions complement the configurable commands above.

## Source slots

While the Sources list is focused, keys **1–9** and **0** place the highlighted source into slots 1–10. Return to the timeline and use **Command+1–9** or **Command+0** to assign that slot to selected cues.

## Reset and conflicts

Reset an individual command to restore its default, or use **Reset All** to restore all defaults. Resolve conflicts reported by the settings window. Commands may share a key where their scopes differ; confirm focus when a key has an unexpected effect. Unassigned commands can be given a binding if you need them.
